# موقع مكتب المسلمى للمحاماة والاستشارات القانونية

موقع ثابت (HTML/CSS/JavaScript) مصمم باللغة العربية واتجاه RTL، ومتوافق مع الهاتف.

## الملفات
- `index.html`: محتوى الموقع وبيانات SEO المنظمة.
- `styles.css`: التصميم والألوان والتجاوب مع الشاشات.
- `script.js`: قائمة الهاتف وسنة حقوق النشر.
- `assets/logo.svg`: شعار رمزي قابل للتعديل.

## قبل النشر — مهم
1. افتح `index.html` وابحث عن `أضف رقم المكتب هنا` و`أضف بريد المكتب هنا` و`أضف العنوان الدقيق هنا`.
2. استبدل `REPLACE_WITH_EMAIL@example.com` ببريد المكتب الحقيقي في رابط `mailto:`.
3. أضف رقم واتساب بصيغة دولية إلى زر واتساب بعد التأكد من الرقم. لا تستخدم رقمًا تجريبيًا.
4. راجع أسماء الخدمات والنبذة التعريفية وتأكد أنها تعكس الخدمات التي يقدمها المكتب فعلًا.
5. راجع كل محتوى قانوني قبل نشره. النصوص الحالية إرشادية عامة ولا تعد رأيًا قانونيًا لحالة بعينها.
6. استبدل وصف الموقع في `meta description` إذا احتجت، وأضف عنوان المكتب الصحيح فقط إذا كان المكتب يستقبل العملاء فيه.

## نشر مجاني عبر GitHub Pages
1. أنشئ حسابًا في GitHub إن لم يكن لديك حساب.
2. أنشئ مستودعًا عامًا جديدًا (Public) باسم `almusallamy-law-site` مثلًا.
3. ارفع محتويات هذا المجلد إلى جذر المستودع، بحيث يكون `index.html` في المستوى الأول.
4. افتح `Settings` ثم `Pages`.
5. في `Build and deployment` اختر `Deploy from a branch`، وحدد `main` و`/(root)` ثم `Save`.
6. انتظر اكتمال النشر، ثم استخدم الرابط الذي سيظهر في صفحة Pages.
قد تتغير أسماء الأزرار قليلًا مع تحديث GitHub.

## تحسين الظهور في Google
- بعد النشر، أضف رابط الموقع في Google Search Console وتحقق من ملكيته بالطريقة التي تقترحها الأداة.
- أرسل خريطة موقع إذا أنشأتها لاحقًا، أو اطلب فهرسة الصفحة الرئيسية من Search Console.
- أضف مقالات أصلية ومراجعة قانونيًا، لكل منها عنوان واضح، وتاريخ تحديث ومصادر موثوقة.
- أنشئ ملف `sitemap.xml` و`robots.txt` بعد معرفة رابط الموقع النهائي.
- لا توجد ضمانة للترتيب الأول في Google؛ النتائج تعتمد على المنافسة وجودة المحتوى والسمعة والإشارات المحلية وغيرها.

## الخصوصية والأمان
لا تضع معلومات موكلين أو مستندات قضايا أو بيانات شخصية على الموقع. استخدم وسيلة تواصل آمنة عند تبادل المستندات.
